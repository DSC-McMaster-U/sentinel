# docs/decisions/

Architecture Decision Records (ADRs) for significant technical choices, such as the vector store, the dependency management tool or the deployment approach.

Name files `NNNN-short-title.md` (e.g. `0001-use-langgraph-for-orchestration.md`) and use these sections: **Status**, **Context**, **Decision**, **Consequences**.

Anyone can propose an ADR through a pull request.
